# V7 setup contract

Setup is a preparation boundary. It may inspect the pinned product baseline, install the assigned method, and prepare the existing-product canon. It does not receive the scenario prompt, the answer bank, evaluator contracts, hidden checks, run IDs, blind IDs or future task answers.

Every setup and canary task uses `gpt-5.6-luna` with reasoning `xhigh`. Setup and canary work is browser-free. The coordinator records only redacted counters, timings, hashes, file inventories and method lifecycle facts.

For new projects the product baseline stays empty. For small and large projects the BMAD, Prist and classic lineages reuse the mature V3 product canon byte-for-byte where the pinned source and method boundary allow it. Future measured requirements do not enter those canons.

Prist has nine independent candidate lineages. Each remains `waiting_for_wi131_release` until the exact deployed stage revision, image and workflow bundle are supplied. No hosted project, connection, kit install or Prist canary is created before that signal.

The setup output is ready for freeze only when the lineage inventory, fingerprint, canary receipt, cost receipt and source-integrity receipt agree with the manifest.
